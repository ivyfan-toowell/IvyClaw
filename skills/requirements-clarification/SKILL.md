# 需求澄清

实现前识别会实质影响结果的未决事项，重点检查：

- 输入与输出的数据结构；
- 对外字段名和兼容性要求；
- 有效值范围、空值和边界行为；
- 错误响应与完成后的验证方式。

先从 `AGENTS.md`、相关代码、测试和适用 Skill 中寻找答案，不询问已经能够从仓库确定的问题。

只有当不同选择会显著改变公开行为，并且无法从仓库确定时，才向用户提出简短、具体的问题。

如果当前任务来自不可交互的脚本：

1. 遵循项目约定和已有接口模式；
2. 选择满足任务所需的最小一致方案；
3. 确保实现与测试采用同一契约；
4. 在最终回答中列出影响公开行为的关键假设。

不要为了追求完整而扩展用户未要求的功能。
